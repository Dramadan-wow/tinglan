# 听澜 5.6.1 下载安装与云端连接

## 下载哪个文件

打开 [5.6.1 发布页](https://github.com/Dramadan-wow/tinglan/releases/tag/v5.6.1)，在 Assets 中选择。当前仓库保持私有，下载需要登录具有仓库访问权限的 GitHub 账号；维护者也可以自行把安装包和连接码发给使用者。

| 文件 | 适用对象 | 启动方式 |
| --- | --- | --- |
| `Tinglan-5.6.1-Client-Setup.exe` | 普通用户，推荐 | 安装后打开“听澜客户端” |
| `Tinglan-5.6.1-Setup.exe` | 需要管理入口或本机服务端的维护者 | 安装后打开“听澜” |
| `Tinglan-5.6.1-Portable.exe` | 需要免安装完整管理版的维护者 | 直接运行；首次会释放运行依赖 |
| `SHA256SUMS.txt` | 校验下载文件 | 与本机计算的 SHA-256 比对 |
| `INSTALL.md` | 不阅读源码即可使用的说明 | 内容与本说明一致 |

支持 Windows 10/11 64 位。Qt 和必要运行库已包含，无需安装 Qt、Visual Studio 或 CMake。发布包使用中性收款占位图，未预置个人收款二维码；会员开通仍由服务器维护者人工核验，不能向占位图付款。

## 普通用户连接云端

1. 安装并打开“听澜客户端”。首次会显示服务器连接设置。
2. 向服务器维护者取得完整文字连接码。在连接码输入框粘贴并导入，核对提供者和显示的证书指纹。
3. 点击“保存并返回登录”。连接码包含服务器地址、端口及公共 CA，客户端会保存配置，之后打开自动使用。
4. 在该服务器注册自己的账号，再登录。以前在另一台服务器或本机创建的账号、聊天记录不会自动迁入。

安装包本身没有预置个人云端地址或账号，所以首次安装不会自动连接到某台服务器。已有连接配置会保留。云端服务器持续运行时，用户和维护者的电脑均可关机，不需要通过维护者电脑中转。

连接码由维护者单独分发，不包含用户密码、管理员密码或私钥。不要关闭 TLS 或忽略证书错误。更换服务器可在登录页打开“服务器连接设置”，重新导入连接码。

## 管理员连接同一云端

1. 安装完整管理版 `Tinglan-5.6.1-Setup.exe`，或运行完整便携版。普通客户端没有管理界面。
2. 在登录页打开“服务器连接设置”，选择云服务器并导入维护者提供的同一份云端连接码，保存。
3. 进入“管理空间”，输入服务器所有者本人设置的管理员账号和密码。新服务器管理员需先由所有者在服务端初始化，没有通用默认密码。

完整管理版支持本机模式，首次启动时可能连接本机服务；要管理云端，必须先切换到云端连接。管理员界面显示的用户、登录记录和会员订单属于当前连接的服务器。

## 常见问题

- 首次显示连接设置：正常，导入一次连接码即可。
- 连接失败或证书校验失败：核对系统时间、连接码来源、服务器是否运行；由维护者检查防火墙和证书有效期。
- 登录或注册一直停在“正在登录并同步资料…”后提示连接不可用：地址能连通但端口不是聊天服务端口。TCP 握手可以由别的进程应答，而 TLS 与登录请求无人处理，超时后连接被丢弃。向维护者确认聊天服务端口（本仓库部署脚本默认 56110，文件服务 56111），重新导入连接码即可。
- 登录提示账号不存在：确认连接的是正确服务器；新建云端库需要注册云端账号。
- 找不到管理入口：检查下载的是完整管理版，而非 `Client-Setup.exe`。
- Windows 显示发布者未知：安装包尚未进行代码签名；核对下载来源和 SHA-256，再自行决定是否运行。
- 看不到 GitHub 下载页：仓库为私有，向维护者申请访问或取得安装包，不要把 GitHub 令牌填入客户端。

可在 PowerShell 中校验下载文件：

```powershell
Get-FileHash .\Tinglan-5.6.1-Client-Setup.exe -Algorithm SHA256
```

结果应与同一发布页 `SHA256SUMS.txt` 对应条目一致。上传 GitHub Release 不会自动发布到中心服务器的客户端更新源，现有用户也可以下载新版安装包手动升级；用户数据和已保存的连接设置应保留。
