## 类名和文件名的区别

- TypesHsx.h 定义枚举和工具函数，没有名为 TypesHsx 的类。
- ProtocolHsx.h 定义 DecoderHsx 以及协议函数，没有名为 ProtocolHsx 的类。
- UpdateInfoHsx.h 和 UpdateStoreHsx.h 定义更新相关常量或自由函数，没有同名类。
- RuntimeHsx.h 定义的是 struct RuntimeHsx。
- WeiboThemeHsx.h 中的控件类实际名为 WeiboHeroHsx。
- 部分内部辅助类定义在 cpp 文件中；Java 和 C++ 的内部类型要连同所属类一起理解。

## 主关系与答辩讲解

用户类族：UserHsx 派生 QQUserHsx、WeChatUserHsx、WeiboUserHsx、OtherUserHsx。

群类族：GroupHsx 派生 QQGroupHsx、WeChatGroupHsx。

策略类族：GroupPolicyHsx 派生 QQPolicyHsx、WeChatPolicyHsx。

组合：DataStore 拥有用户和群，用户拥有服务账号，服务账号拥有好友记录，群拥有当前策略。

关联：群成员、好友和消息端点通过 ID 关联用户；业务管理器保存 DataStore 引用。

依赖：消息管理器在发送时调用好友和群管理器的规则；存档与编码工具在执行操作时使用仓库。

讲解时先讲 src 中的 34 个课程核心类，再用 workspace、network、server、gui 和 mobile 说明扩展。内部辅助类与测试类用于回答实现细节，不需要在开场逐个背诵。
