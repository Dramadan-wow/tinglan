# 听澜 5.3

Windows x64 课程版。打开便携 EXE 或安装后启动听澜，先在登录页注册账号。发布包不携带已有用户、密码、聊天记录或测试账号。

本版只保留 QQ、微信、微博。微商、微唱、微走、微笑不再提供注册或开通；新建存档不自动生成演示人物。已有真实账号与密码继续使用。

## 朋友圈和微博

- 朋友圈：仅自己与双向好友可见，可发文字和一张图片；原有广场动态迁入朋友圈。取消好友关系后，对方不再能取回你的朋友圈内容，但不能撤回已被保存或截图的内容。
- 微博：仅开通微博服务的用户可用。登录后进入“账号 → 开通服务”，选择微博；再用左下角“当前服务”切换到微博，即进入独立的“绚色微博”空间。QQ、微信界面不再显示微博入口。已有微博账号可直接切换，无需重新注册。
- 微博是已开通用户共享的公开平台，无需加好友即可浏览、发布、点赞、评论、关注。支持按当前列表的作者、文字与 `#话题#` 搜索，右侧话题来自真实帖子。服务端也校验开通状态，不能绕过界面访问；关闭微博服务不会删除原帖子或私信，重新开通后恢复可见。
- 微博使用粉色、深紫与荧光黄的独立主题，含伊冯灵感横幅、我的关注与微博私信入口。切回 QQ／微信恢复原聊天界面。
- 点公开帖子的“私信”即可联系作者。在“微博 → 私信”查看并回复陌生人；提供未读提示与屏蔽。对方回复前，24 小时内最多发 3 条消息。
- 每个频道显示最近 20 条可见动态，每帖显示最近 10 条评论，私信显示最近 200 条；旧记录仍保存在服务器，暂未提供分页。图片会压缩到最长边 640 像素以内，一帖一图；不适合传输原图。
- 这是听澜自有平台，参考微博的布局与交互，并未连接新浪微博账号或数据。

## 装扮和会员

在线会员订单和权益由中心服务器保存。主题、头像、背景与装扮选择保存在本机；暂不跨设备同步个人图片。在线模式更换这些外观不再触发“本机数据操作”错误。

|档位|金额|有效期|权益|
|---|---:|---|---|
|星芽|1 元|7 天|薄荷、樱花气泡；青芽头像框、薄荷小火人|
|月汐|6 元|30 天|包含星芽，增加糖果、海盐、落日气泡及月汐装扮|
|星河|128 元|365 天|包含月汐，增加极光、银河气泡及星河装扮|
|云境|648 元|永久|全部气泡、头像框与小火人装扮|

免费用户也可以发帖、聊天、更换主题、头像和背景。到期自动回到免费装扮。扫码付款后提交凭证只是生成待核验订单；软件没有接入微信支付回调，不会自动确认到账。当前二维码为项目所有者提供的收款码。

5.2 管理空间已连接中心服务器。在登录页选择“管理空间”，使用服务器管理员凭据登录，在“充值订单核验”查看所有用户申请并核验或驳回，结果实时同步。详情见项目中的《管理员使用说明》。

服务器维护者仍可使用命令行核验：先关闭客户端，等待本机服务闲置 60 秒退出，再在安装目录或便携解压目录运行 PowerShell：

```powershell
$cfg = "$env:LOCALAPPDATA/Hsx Coursework/听澜/server.json"
.\im_server.exe --config $cfg --orders
.\im_server.exe --config $cfg --review-order "订单 UUID" --approve --note "实际到账的完整交易单号"
# 驳回时不传 --approve，note 填具体原因
```

退出服务器后才可核验，避免两个进程同时改库；核验后重新打开客户端，会员状态会同步。仅显式离线模式和旧控制台管理员仍管理本地课程数据；新版管理空间管理服务器数据。服务器维护者拥有数据库文件访问权；本机便携模式不适合作为真正付费服务的可信后台。

## 数据与连接

- 默认数据目录：`%LOCALAPPDATA%/Hsx Coursework/听澜`。可用环境变量 `TINGLAN_HOME` 指定其他独立目录。
- 默认自动启动本机中心服务（127.0.0.1:56110），方便本机运行。所有客户端关闭后，服务闲置 60 秒退出。
- 默认配置只在本机可用。给另一台电脑发送 EXE，并不会自动连接到同一个服务器。
- 跨电脑部署需由维护者在上述目录的 `client.json` 配置同一个服务器的域名、端口、TLS 与 CA；将 `autoStartLocalServer` 设为 `false`。普通界面不展示 IP。正式联网必须部署证书并启用 TLS；明文模式仅允许回环地址。
- 同机开两个客户端时，第二个使用 `im_desktop.exe --data "另一份本机缓存.txt"`，共用同一份 client.json；账号仍由同一个服务端认证。默认同一份本机缓存有文件锁。
- 用户库、好友、聊天、动态、私信和会员订单位于 `server.json` 的 `workspaceFile` 指向的 SQLite 文件（默认 `server/workspace.sqlite`，已恢复的本机数据可能使用另一个文件名）；server/users.json 用于兼容独立网络账号。备份前关闭客户端并等待服务退出，复制整个数据目录。
- 现有开发环境的数据没有被删除，也没有放入发行包。若要迁移旧服务器，请停服备份后复制原服务器数据，并调整 server.json；不要将空库覆盖旧库。首次升级旧动态表会在原库旁生成 `.before-social-v5.sqlite` 备份。

## 便携版与安装版

便携 EXE 内含程序和 Qt 运行库，第一次启动会释放到 `%LOCALAPPDATA%/Tinglan/Runtime/<版本哈希>`；因此文件可以单独分发，但不是静态链接 Qt。后续启动复用该目录，首次解压需要 Windows PowerShell 和可用磁盘空间。

安装版安装到当前用户目录，含开始菜单入口、可选桌面快捷方式与卸载程序。卸载保留独立用户数据。两种版本共用同一用户数据目录，不应同时打开同一缓存。

当前发行文件未做代码签名。尚未在另一台干净 Windows 电脑、Linux、Android 或 iOS 实机验证。Qt/第三方许可证与声明在 licenses 目录；动态 Qt DLL 可替换为兼容版本。

微博横幅为 AI 生成的伊冯灵感同人插画，并非官方素材或官方合作。角色参考《明日方舟：终末地》[官方干员页面](https://endfield.gryphline.com/zh-tw/operator)。本次更新不会初始化或覆盖已有用户库。
