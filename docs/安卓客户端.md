# 听澜 Android 1.0.0

原生 Android Java 普通客户端，直接使用现有 Qt 服务端的 v1 TCP/TLS 协议，不需要手机中转服务、微信云托管或维护者电脑。桌面端版本仍为 5.6.1，安卓客户端独立使用 1.0.0 版本号。

## 安装与连接

1. 将 `Tinglan-Android-1.0.0.apk` 传到 Android 8.0 或更高版本手机，打开安装。系统如询问是否允许当前文件管理器安装应用，按手机提示自行选择；这是直接安装包，不是应用商店发布。
2. 打开“听澜”，点击右上角“连接”，粘贴服务器维护者提供的 `TINGLAN1.` 文字连接码。核对服务器地址及公共 CA 指纹后保存。
3. 选择 QQ、微信或微博，输入该服务器的昵称与密码登录。没有账号时点击注册，设置至少 8 字节的密码。
4. 连接信息会保存在应用私有目录，密码只保留在当前会话内存。退出账号或应用进程被系统结束后，需要重新输入密码。

APK 不包含个人服务器配置、公共/私有证书、密码、真实账号库或个人收款码。已有电脑端云端连接码可以原样使用。不要把服务器私钥放进手机，也不要忽略 TLS 错误。

## 已支持

- 昵称登录、注册，QQ / 微信 / 微博服务视图。
- 服务器联系人、发送好友申请、接受、拒绝和撤销申请。
- 私聊、群聊、未读计数、已读标记、消息收藏、两分钟内撤回本人消息。
- 创建群、申请加入 QQ 群，群成员和公告、管理者审批入群申请。
- 朋友圈和微博动态查看、文字发布、点赞、评论；可查看服务端同步的动态图片。
- 个人昵称和所在地编辑、服务切换、退出登录。
- 严格 TLS 证书链、有效期和主机名/IP 校验；断线重连，失败操作不自动重复发送。

## 当前限制

同一账号目前由现有服务端限制只能在一台设备登录，手机登录前请先退出电脑端账号。前台保持实时连接，后台可能受手机省电策略暂停；本版没有系统离线推送、文件传输、图片发布、管理后台、支付或自动安装升级。QQ群需要管理员审批；微信群邀请仍可从完整桌面端操作。

数据由现有中心服务器保存，卸载本应用不会删除服务器账号和聊天记录。退出账号会清除本次内存里的消息和密码。新建云端库和旧本机库相互独立。

## 从源码构建

需要 JDK 17 或更高、Google Android SDK Platform 35 和 Build Tools 35.0.0。使用官方 `aapt2`、Java 编译器、D8、zipalign、apksigner 构建，不依赖 Gradle、NDK 或 Qt Android SDK。安装后的 APK 不依赖这些开发工具。

```powershell
python scripts/build_android.py --sdk-root "你的AndroidSDK目录" --java-home "你的JDK目录" --keystore "源码目录外的签名密钥.p12" --storepass-file "源码目录外的签名密码文件.txt"
```

产物默认位于 `dist/android/Tinglan-Android-1.0.0.apk`，旁边生成 `SHA256SUMS.txt`。脚本会验证签名并记录清单信息，构建日志位于 `build-package/android/build.log`。密钥和密码不得提交 Git；后续覆盖升级必须继续使用同一签名密钥。

Android 工具与签名流程参考 [Android 官方 AAPT2 文档](https://developer.android.com/tools/aapt2) 和 [apksigner 文档](https://developer.android.com/tools/apksigner)。

协议集成检查源码在 `tests/android/AndroidProtocolChecks.java`，使用隔离测试服务器、数据库及生成的测试证书，不操作生产账号。
