# 听澜 Android 1.3.3

原生 Android Java 普通客户端，直接使用现有 Qt 服务端的 v1 TCP/TLS 协议。安卓客户端独立使用 1.3.3 版本号，配套服务器 5.7.3（检查更新需要）与桌面端 5.7.2。

1.3.3 新增：应用内检查更新。见下方「升级」。

1.3.0 新增：勾选“下次打开自动登录”后，再次打开应用会直接登录；电脑和手机可以同时登录；“扫一扫”扫描电脑端的登录二维码，在手机上确认后电脑即登录；私聊里加入与电脑端相同的小火人，可与好友一起换装。

1.2.0 界面向电脑端看齐：登录页保留山水绿，登录后与电脑端一样使用浅蓝工作区配色；导航改为会话、好友、群组、朋友圈和我的，右上角铃铛进入通知页处理好友与入群申请，未读和待处理数量用红色角标提示。会话列表显示彩色圆形头像（或已同步的自定义头像与头像框）、最后一条消息、时间和未读数，并支持搜索；聊天页显示双方头像、日期分隔、每位发送者在电脑端选择的气泡样式，以及名称、时间和已读状态，输入区带表情按钮和圆形发送按钮。

平板横屏使用与电脑端相同的左侧边栏，会话页为“会话列表 + 聊天”双栏。微博保留伊冯灵感插画与粉紫主题及独立的广场、关注、私信和我的导航。横竖屏切换保留当前会话及聊天草稿。

## 安装与连接

1. 从 [5.7.2 下载页](https://github.com/Dramadan-wow/tinglan/releases/tag/v5.7.2) 取得 `Tinglan-Android-1.3.2.apk`，传到 Android 8.0 或更高版本设备，打开安装。可直接覆盖 1.0.0 至 1.3.1，沿用原签名和已保存的连接信息。微信传输可能将文件改为 `.apk.1`，请在系统文件管理中删掉最后的 `.1` 再安装；也可传输附带的 ZIP，解压后安装。
2. 打开“听澜”，点击右上角“连接”，粘贴服务器维护者提供的 `TINGLAN1.` 文字连接码。核对服务器地址及公共 CA 指纹后保存。
3. 选择 QQ、微信或微博，输入该服务器的昵称与密码登录。没有账号时点击注册，设置至少 12 字节的密码。
4. 连接信息会保存在应用私有目录，密码只保留在当前会话内存，从不写入手机。勾选“下次打开自动登录”时，服务器会为这部手机签发一个登录凭证（保存在应用私有目录），之后打开应用自动登录；凭证 30 天未使用、在“我的”退出账号、修改该服务密码、被管理员重置密码或强制下线后失效，需要重新输入密码。不勾选时，退出账号或应用进程被系统结束后需要重新输入密码。

APK 不包含个人服务器配置、公共/私有证书、密码、真实账号库或个人收款码。已有电脑端云端连接码可以原样使用。不要把服务器私钥放进手机，也不要忽略 TLS 错误。

## 升级

1.3.3 起，手机端可以从听澜服务器升级，不必再手动传 APK：

- **自动检查**：登录后最多每 6 小时检查一次，有新版本时弹出“发现新版本”，显示更新说明和大小。
- **手动检查**：在“我的”页面底部，点版本号旁的“检查更新”。
- 点“下载并安装”后，安装包通过与聊天相同的 TLS 连接（严格校验证书）分片下载，完成后核对 SHA-256；安装前再核对包名、版本号比当前新、签名与已安装的听澜一致，任何一项不符都会删除安装包。
- 安卓不允许应用静默安装。第一次升级时，系统会要求在设置里允许听澜“安装未知应用”，打开后返回听澜会继续；之后每次在系统安装界面点“更新”即可。聊天记录、连接信息和自动登录都会保留。
- 需要服务器 5.7.3 或更高版本，并由维护者把 APK 发布到服务器（见下）。服务器尚未开启时，“检查更新”会提示“服务器还没有开启安卓更新”。

1.3.2 及更早的版本没有这个功能，需要按上面的方式手动安装一次 1.3.3。

**维护者发布安卓更新**：`scripts/build_android.py` 在 APK 旁生成 `android-update.json`（说明取自 `mobile/android/update-notes.txt`）。把 APK、`android-update.json`、`scripts/publish_client_update.py`、`server/deploy/publish-update.sh` 和 `SHA256SUMS` 放到服务器同一个目录，以 root 运行 `bash publish-update.sh`。服务不需要重启，只更新 `updates/android-stable.json` 和对应 APK；不允许降级，也不允许用不同内容覆盖已发布的版本。

## 已支持

- 昵称登录、注册，QQ / 微信 / 微博服务视图。
- 按对方完整的昵称或服务号码查找用户并发送好友申请（不展示全部用户）；在通知页接受、拒绝和撤销申请，管理者审批入群申请。
- 私聊、群聊、未读计数、已读标记、消息收藏、两分钟内撤回本人消息。
- 创建群、申请加入 QQ 群，群成员和公告、管理者审批入群申请。
- 朋友圈和微博动态查看、文字发布、点赞、评论；可查看服务端同步的动态图片。
- 微博公开广场、关注筛选、本人微博、关注/取消关注；从公开微博发起私信、收件箱、回复和已读同步。
- 在“我的”开通当前账号的微博服务，不需要重新建立另一套个人资料。
- 个人昵称和所在地编辑、服务切换、退出登录；可选的自动登录。
- 扫一扫：在会话页右上角或“我的”打开，扫描电脑端“手机扫码登录”的二维码，确认后电脑以你的账号登录，手机保持登录。首次使用会请求相机权限，画面只在手机上识别。
- 小火人：私聊里悬浮显示与好友的连续聊天天数和等级，轻点打招呼、按住拖动、长按打开两人共用的衣橱；会员款按你的会员档位解锁。
- 会员与充值：在“我的”进入，选择档位后用内置的微信收款码付款（可保存到相册，在微信扫一扫里从相册识别），提交交易单号或付款备注，由管理员核验后开通；可查看和取消自己的订单。
- 严格 TLS 证书链、有效期和主机名/IP 校验；断线重连，失败操作不自动重复发送。

## 当前限制

电脑和手机可以同时登录同一账号（需要服务器 5.7.0 起）；同一账号在另一部手机登录时，本机会提示并下线。前台保持实时连接，后台可能受手机省电策略暂停；本版没有系统离线推送、文件传输、图片发布、管理后台或自动扣款；升级需要你在系统安装界面确认，不能静默安装。QQ群需要管理员审批；微信群邀请仍可从完整桌面端操作。

数据由现有中心服务器保存，卸载本应用不会删除服务器账号和聊天记录。退出账号会清除本次内存里的消息和密码。新建云端库和旧本机库相互独立。

## 从源码构建

需要 JDK 17 或更高、Google Android SDK Platform 35 和 Build Tools 35.0.0。使用官方 `aapt2`、Java 编译器、D8、zipalign、apksigner 构建，不依赖 Gradle、NDK 或 Qt Android SDK。安装后的 APK 不依赖这些开发工具。

```powershell
python scripts/build_android.py --sdk-root "你的AndroidSDK目录" --java-home "你的JDK目录" --keystore "源码目录外的签名密钥.p12" --storepass-file "源码目录外的签名密码文件.txt"
```

产物默认位于 `dist/android/Tinglan-Android-1.2.0.apk`，版本从清单读取，旁边生成 `SHA256SUMS.txt`。脚本会验证签名并记录清单信息，构建日志位于 `build-package/android/build.log`。密钥和密码不得提交 Git；后续覆盖升级必须继续使用同一签名密钥。

仅将 `assets/art/yvonne-social.png` 与 `assets/art/mist-river-v3.png` 两份已有公开插画复制进构建资源。伊冯插画为项目原有同人素材，非官方合作；不复制收款图、私钥或个人连接配置。

Android 工具与签名流程参考 [Android 官方 AAPT2 文档](https://developer.android.com/tools/aapt2) 和 [apksigner 文档](https://developer.android.com/tools/apksigner)。

协议集成检查源码在 `tests/android/AndroidProtocolChecks.java`，使用隔离测试服务器、数据库及生成的测试证书，不操作生产账号。

原生界面检查在 `tests/android-ui/`，测试数据只进入独立的测试 APK。`Android native UI` 工作流使用临时签名、隔离安卓模拟器，检查手机与平板布局（含登录、微博、会话列表、聊天、好友、通知和平板双栏会话）并保存渲染截图；临时签名的 CI 产物不用于覆盖正式安装。
