# 听澜 5.5：给朋友的安装包

给朋友发送 `Tinglan-5.5.0-Client-Setup.exe` 即可。双击安装，Qt、加密组件和运行库均已包含，无需安装开发环境或解压文件。普通客户端不包含管理后台或本机服务器。电脑 A 保留完整管理版，并独立启动中心服务器。

第一次启动会打开连接设置。电脑 A 在已部署的局域网/云服务器配置中点击“复制连接码”，以文字发送给朋友。电脑 B 粘贴到连接码输入框，自动识别服务器地址、端口与公共 CA，核对发送者和证书指纹后点击“保存并返回登录”，即可注册或使用原账号登录。连接配置保存在用户目录，重开软件仍有效。

连接码只含地址、端口和公共证书，不含用户密码、管理账号、私钥或数据库。请通过可信渠道取得并核对连接码；校验码只能发现传输损坏，不能证明是谁发出的。客户端始终验证 TLS 证书、有效期和连接地址。改变服务器 IP 后，必须重新签发匹配 SAN 的服务端证书，不能只改连接码。

已有局域网配置可运行：

```powershell
python scripts/export_connection_code.py --client-config "已有局域网配置/client/client.json" --out "connection-code.txt"
```

生成的 `connection-code.txt` 可打开后复制全文发送。首次配置服务器仍使用 `scripts/prepare_lan.py`，地址由部署者填写，不会使用当前 Wi-Fi 地址。新版脚本提供连接码，无需再分发客户端 ZIP。

头像、气泡、头像框和小火人皮肤由同一中心服务器保存并同步，头像上传时会压缩。会员装扮由服务器核验。旧本机装扮在首次登录新版服务器时尝试迁入（不会覆盖已有服务端装扮）；主题色和聊天背景仍是每台电脑的个人偏好。原文件保留。

5.5 起普通客户端启动时和每 6 小时自动检查中心服务器的新版本；也可点击“软件更新”。确认后下载安装、升级并重启，用户资料不清空。5.4 及更早版本需要先安装一次新版。详见 [自动更新说明](自动更新.md)。连接码用于连接配置，不用于传输程序代码。安装包尚未签名，Windows 可能显示来源确认提示。

本电脑升级已有局域网部署：先在原服务器窗口按 Ctrl+C 停止旧服务，再双击项目根目录“启动中心服务器.cmd”。该入口使用当前 5.5 服务端和原局域网 server.json，保留原库和证书，不检测或更改 Wi-Fi 地址。然后双击“启动中心客户端.cmd”，电脑 A 使用同一份原局域网配置登录。朋友安装 5.5 普通客户端并导入同一服务器的连接码。只有一个既有部署时启动入口自动选中该配置；多份部署时会要求输入配置路径。本机开发入口仍保留。
