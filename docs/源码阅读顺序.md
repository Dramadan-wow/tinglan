# 听澜源码阅读顺序

适用于当前桌面 5.7.0 / Android 1.3.1 源码。按下面的章节和表格从上到下读，即可覆盖项目自写源码、测试与构建部署脚本；第三方二维码库放在最后。

想先理解类为什么这样拆、继承/组合关系和功能如何完成，可先看 [类设计思路与 UML](类设计与UML.md)，再按本清单逐个读文件。

## 怎么读

每组 C++ 文件先看 `.h` 的职责、成员和公开接口，再看 `.cpp` 的实现。表格中的“头 / 实现”都可以点击。第一次遇到后面章节的类，先记住它负责什么，读到对应章节再展开。

每读完一组，记下四件事：**它保存什么数据、谁调用它、它调用谁、失败时怎样处理**。不要一开始逐行钻进 Qt 布局代码；先把一项业务的输入、校验、状态变化和输出连起来。

推荐主线：**工程与入口 → 数据模型 → 业务管理器 → 控制台 → 协议与序列化 → 服务端 → Qt 会话与页面 → 扩展功能 → Android → 测试 → 构建部署 → 第三方库**。

先读 [README](../README.md)，再看根 [CMakeLists.txt](../CMakeLists.txt)。本项目中的几个 `main.cpp` 属于不同程序。

### 先分清这几组概念

- `UserHsx` 是一个人；`ServiceAccountHsx` 是这个人在 QQ、微信或微博中的服务账号。
- `DataStoreHsx` 是内存对象集合；`StorageHsx` 读写本机文本存档；`WorkspaceBackendHsx` 把中心业务状态持久化到 SQLite。
- `AccountManagerHsx` 等管理器执行业务规则；`AppSessionHsx` 把桌面界面、本机业务和远程请求连接起来。
- 正常桌面聊天走 `workspace_command` 中的 `chat.send`，保存后同步业务快照。`NetworkPageHsx` 中的 `sendChat()` 是另一条独立转发演示路径。控制台 `NetChatHsx` 又有自己的旧式点对点协议。
- `ServiceHsx` 保留了一些旧枚举值用于兼容存档；当前向用户提供的服务只有 QQ、微信、微博，留意 `ActiveServiceCountHsx` 和 `activeService()`。

这里有一个容易误解的存储细节：核心 `DataStore` 由 `persist()` 编码后保存在 SQLite 的 `state.payload` 中；社交、操作去重、设备凭证等还有独立表。不要直接假设每一个 C++ 领域类都对应一张 SQL 表。

读完应能说明：客户端传来的操作者字段为何不能替代已认证连接身份；同一个请求 ID 重发怎样处理；业务失败如何回滚；不同用户为什么收到不同快照。

## 17. 读完后，用五条调用链自测

### A. 普通桌面登录

```text
gui/client_main.cpp
  → RuntimeHsx / ConnectionDialogHsx
  → LoginDialogHsx
  → AppSessionHsx::loginRemote
  → ChatClientHsx::start / open / login
  → ProtocolHsx 编码 + TLS
  → ChatServerHsx::workspaceLogin / admit
  → WorkspaceBackendHsx 凭据查询与账号状态
  → ChatServerHsx::synchronize / sendSnapshot
  → ChatClientHsx::handle 组装 workspace_sync
  → AppSessionHsx 的 workspaceSnapshot 回调更新内存数据
  → remoteLoginFinished → MainWindowHsx
```

### B. 发送一条普通私聊消息

```text
ChatPageHsx::send
  → AppSessionHsx::command("chat.send", ...)
  → ChatClientHsx::workspaceCommand
  → ProtocolHsx 编码 + TLS
  → ChatServerHsx::read / handle
  → WorkspaceBackendHsx::command
  → MessageManagerHsx::sendPrivate / append
  → persist + operations 记录 + SQLite 提交
  → workspace_result + 各用户自己的 workspace_sync
  → ChatClientHsx 的 workspaceResult / workspaceSnapshot 信号
  → AppSessionHsx 更新数据并发出 changed
  → ChatPageHsx::refresh / showHistory
```

本机模式在 `AppSessionHsx::command()` 中执行页面传入的本地回调，走 `MessageManagerHsx` 和 `StorageHsx`；两种模式共用部分界面与业务规则。

### C. 好友申请与群申请

```text
FriendsPageHsx / GroupsPageHsx
  → AppSessionHsx::command
  → workspace_command
  → WorkspaceBackendHsx::command
  → FriendManagerHsx / GroupManagerHsx 校验并修改
  → SQLite 提交 + 按用户同步
  → RequestsPageHsx 展示待办
  → 接受 / 拒绝命令再次回到服务端
```

### D. 文件传输

```text
登录后的文件会话授权
  → AppSessionHsx 将 fileSession 交给 FileTransferManagerHsx
  → 聊天页选文件 → upload → 哈希 / HTTPS 分块上传
  → FileStorageServiceHsx 校验授权、配额和内容并完成文件
  → fileReady → ChatServerHsx 通知相关客户端
  → FileTransferManagerHsx::refresh → FileMessageCardHsx 展示
  → 接收者 download → HTTPS Range 下载 → SHA-256 校验
```

### E. 手机扫码登录桌面

```text
QrLoginDialogHsx / AppSessionHsx::loginRemoteQr
  → ChatClientHsx → qr_start → ChatServerHsx::qrStart
  → 桌面显示票据二维码
  → Android ScanActivity 识别
  → 已登录手机发送 qr_scan / qr_confirm
  → ChatServerHsx::qrAction 校验票据与身份
  → admit + WorkspaceBackendHsx::issueToken
  → 桌面收到登录结果与业务快照
```
