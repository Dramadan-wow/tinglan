# 听澜 · 山水有相逢

本次前端围绕「江上薄雾、青绿山色、留白书页」重新设计。登录页用大幅山水画建立氛围，进入程序后以深青绿导航、米白底色和浅绿消息气泡延续同一风格。

## 视觉与交互

- 登录：双栏布局、宋体品牌与诗句、用户 / 管理员双入口、昵称输入、密码显隐；音乐播放器采用深色半透明卡片。
- 导航：手绘矢量路径图标，分组菜单、当前状态、底部用户卡片。
- 会话：自绘头像、名称、最后消息、时间与未读角标；搜索可按昵称或最后一条消息筛选。
- 聊天：区分收发双方的气泡、日期分隔、昵称与回执、独立输入区和空白状态插画图标。
- 表格与表单：统一间距、圆角、选中与悬停色，增加清晰的标题层次。

## 实现位置

界面采用 Qt Widgets 原生布局。山水图由 `LandscapeHsx` 的 QPainter 裁切并绘制圆角与渐变；图标由 `IconHsx` 用 QPainterPath 绘制；会话列表由 `ConversationDelegateHsx` 绘制。配色与控件风格集中在 `ThemeHsx` 中。

背景与音乐通过 `assets/login.qrc` 编译进可执行文件，运行时无需网络，也无需从源码目录加载素材。业务仍通过 `AppSessionHsx` 调用 C++ 核心模块。
