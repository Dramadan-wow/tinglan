# 听澜 5.2 在线管理员

## 进入后台

双击项目根目录“启动管理员模式.cmd”，或在新版登录页选择“管理空间”。该入口通过同一个中心服务器认证，读取服务器 SQLite 中的账号、在线状态、登录日志和会员订单，不再读取旧客户端缓存作为在线管理数据。

已有管理员使用原服务器管理员账号与密码，本次升级不重置凭据。之前导入的课程账号默认管理员为 admin；如果已经修改密码，使用修改后的密码。普通账号、群管理员、客户端提交的 admin 标志不能代替服务器管理员认证。

“启动管理员模式.cmd”使用单独的本机缓存，允许和一个普通用户客户端同时运行；两者连接相同的 client.json。控制台管理员和显式 --offline-demo 模式仍只管理本地课程存档。

## 实时数据

- 注册用户、允许登录、禁止登录与当前在线人数来自服务器，注册或断线后自动更新。
- 登录成功、失败、注册、断线登出及管理操作写入服务器数据库；用户日志显示昵称与内部 ID。
- 后台显示最近 500 条日志，服务器保存最近 2000 条。过去未被记录的服务器事件不能补造；可导入已有本地日志，但不修改账号或密码。
- 这里的登录记录是登录尝试与结果，不是每次登录必须人工审批的工作流。允许登录的账号仍可直接凭密码进入。
- 数据同步状态在后台底栏显示；断线自动重连，断线期间管理操作不会假装成功。

## 账号管理

选择用户后可允许登录、禁止登录、强制登出、重置指定服务或全部服务的密码。禁止登录和重置密码会结束真实网络连接。强制登出会停止该客户端的自动重连，账号仍可手动重新登录。重置密码至少 8 字节，不会自动解除禁止登录。

右上角可修改管理员密码，需要原密码与重复确认；服务器保存新摘要并结束其他管理员会话。当前管理员重连会使用新密码。所有管理操作由经过认证的服务端连接授权，管理员快照不包含密码摘要或私人聊天正文。

## 会员申请

进入“充值订单核验”，查看所有用户提交的待核验和历史订单；优先显示待核验订单，最多 2000 条。用户新提交订单会自动出现。

先到微信收款记录核对付款人、金额和交易单号，再点击“确认到账并开通”，输入完整交易单号并勾选已核验。未付款或信息不符可驳回并填写原因。审核人、时间、备注及会员权益保存在服务器，用户端实时同步。重复订单或已使用的交易单号不能再次核销。

这仍是人工核验系统，未接入微信支付自动回调；看到申请不等于收到款项。本次测试仅审核隔离测试订单，不处理真实订单。

## 新服务器首次设置或维护

全新数据库不自动创建固定管理员密码。停止服务后，在服务端所在目录通过环境变量提供管理员密码（避免放入命令参数或源码）：

```powershell
$cfg = "$env:LOCALAPPDATA/Hsx Coursework/听澜/server.json"
$secret = Read-Host "设置服务器管理员密码（至少 8 字节）" -AsSecureString
$env:TINGLAN_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new("", $secret).Password
try { .\im_server.exe --config $cfg --set-admin admin }
finally { Remove-Item Env:TINGLAN_ADMIN_PASSWORD }
```

该维护命令拥有数据库访问权限时才能使用，会明确重设管理员凭据；正常升级不要执行。服务运行时数据库锁会拒绝维护操作。

旧日志导入只在停服、备份后执行：

```powershell
.\im_server.exe --config $cfg --import-audit "旧本地存档.txt"
```

只导入身份能与现有账号匹配的日志，并保留原始时间；重复日志跳过。不会导入或覆盖旧存档中的用户密码、管理员密码或会员权益。

## 数据保护

以 server.json 的 workspaceFile 为准，不要用空数据库覆盖旧数据库。本机已恢复数据可能叫 workspace-restored-20261012.sqlite。升级前关闭客户端，等待本机服务退出，备份整个用户数据目录。跨电脑使用时应连接同一 TLS 服务器；本机明文模式只允许回环地址。
